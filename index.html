Data Storage & Security Disclosure

📍 Local Device Storage: All prize configurations, custom photos, stock counts, classroom settings, and student spin history are stored exclusively in this browser's localStorage.

This means your data remains strictly on this computer and browser. If you switch to another device or clear your browser data, the wheel will return to default settings.

⚠️ Client-Side Security Advisory: The teacher password check is implemented entirely in client-side JavaScript to keep the site 100% serverless and ready for GitHub Pages hosting. While it effectively prevents regular students from seeing editing controls in class, students with knowledge of browser Developer Tools (F12) can inspect the JavaScript code and localStorage.

Teaching Demonstration Quick Tips:

  • Click 📺 Present in the top menu to enter distraction-free full-screen mode before inviting students to the front.
  • You can type the student's name or click their name from the quick roster chips.
  • Press Enter to spin instantly.
  • After each celebration, click Play Again / Next Student to immediately prepare the stage for the next learner.
